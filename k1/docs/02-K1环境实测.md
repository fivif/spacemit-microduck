## 5. 已完成的动作

1. `apt-get install -y onnxruntime cmake libudev-dev pkg-config`
2. rustup + rustc 1.98.1
3. 开发机打包 `microduck` → scp → `/opt/microduck-k1/` → 解包
   - 分支 `k3-sim-port`,`duck-control/src/sim.rs`(17 026 B)在位
   - 依赖审计:`Cargo.lock` **519 个 registry 源、0 个 git 源**(便于离线 vendor)
4. `cargo build --release --workspace --exclude mediad duck-detect pet-detect`
   —— 结果见 05。

## 6. 复现探查命令

```bash
ssh root@<board> '
cat /proc/device-tree/model; echo
head -12 /proc/cpuinfo
cat /etc/os-release | head -3
nproc; free -h | head -2; df -h / | tail -1
ldd --version | head -1
apt-cache policy onnxruntime cmake
ls -la /usr/lib/libonnxruntime* 2>/dev/null
'
```

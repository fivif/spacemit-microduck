## Python(为未来仿真/工具预留,<tools> 已用)

- 系统 python3 = 3.14.4;**PyPI 无 riscv64 轮子**(mujoco riscv64 wheel 数 = 0,已核实)
- venv `/opt/<tools>/.venv`(py3.12):numpy 1.26.4 、torch 2.4.1(CPU)、onnx
- 结论:仿真环境保持 x86 不动(Microduck 决策:仿真/训练不上 K3)

## 风险提示(实测记录)

- `numpy` import 时 `cpuinfo: processor architecture is not supported` —— RISC-V 下 cpuinfo 库无支持,
  纯告警,不影响(1.26.4 工作正常)。
- 无 cmake/ninja:若日后要在 K3 编译 C++(如 MuJoCo),需先 `apt install cmake ninja-build python3-dev`。
